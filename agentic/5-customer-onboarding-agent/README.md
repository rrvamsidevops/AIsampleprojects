# Customer Onboarding Agent

## Overview
An agent that guides customers through multi-step enrollment workflows with validation, account creation, and confirmation notifications. Built with Claude 3.5 Sonnet.

## Purpose
Demonstrates stateful multi-step workflows:
- Multi-step enrollment process
- Input validation across steps
- Account creation and setup
- Confirmation notifications
- State persistence
- Error handling and retry

## Features
✅ Multi-step guided enrollment
✅ Input validation per step
✅ Account creation
✅ Email/SMS notifications
✅ State persistence
✅ Error recovery
✅ Progress tracking

## Agent Loop
1. User starts enrollment
2. Agent collects basic info
3. Validate and store
4. Request payment info
5. Validate payment details
6. Create account
7. Send confirmation
8. Guide to next steps

## Testing Focus (Later)
- State persistence across steps
- Validation correctness
- Account creation accuracy
- Notification delivery
- Error handling and recovery
- Data consistency
- Compliance with regulations
