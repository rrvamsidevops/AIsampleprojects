# Content Generation Agent

## Overview
An agent that generates content for multiple channels (blogs, social media, emails) while maintaining tone consistency and fact-checking. Built with Claude 3.5 Sonnet.

## Purpose
Demonstrates content workflow automation:
- Multi-channel content creation
- Tone and brand consistency
- Fact-checking before publishing
- SEO optimization
- Content variation generation
- Quality review workflows

## Features
✅ Blog post generation
✅ Social media content creation
✅ Email content generation
✅ Tone consistency across channels
✅ Fact-checking integration
✅ SEO optimization
✅ Multi-variant generation

## Agent Loop
1. User provides content brief
2. Agent plans content strategy
3. Generate draft content
4. Fact-check content
5. Optimize for channel (SEO/length)
6. Review for tone consistency
7. Generate variations
8. Return final content

## Testing Focus (Later)
- Content quality and relevance
- Tone consistency across channels
- Fact-checking accuracy
- SEO optimization effectiveness
- Variation diversity
- Grammar and style correctness
- Brand voice preservation
