# Travel Planning Agent

## Overview
An autonomous agent that plans complete trips by searching flights, hotels, activities, calculating costs, and building itineraries. Built with Claude 3.5 Sonnet.

## Purpose
Demonstrates complex multi-constraint workflows:
- Flight search and booking
- Hotel search and availability
- Activity recommendations
- Itinerary generation
- Budget constraint management
- Cost optimization

## Features
✅ Flight search and comparison
✅ Hotel availability checking
✅ Activity recommendations
✅ Itinerary generation
✅ Budget tracking
✅ Price optimization
✅ Conflict resolution (timing, budget)

## Agent Loop
1. User provides travel request
2. Agent plans trip structure
3. Search flights
4. Search hotels
5. Find activities
6. Check conflicts (dates, timing)
7. Calculate total cost
8. Optimize for budget
9. Generate final itinerary

## Testing Focus (Later)
- Flight data accuracy
- Hotel availability correctness
- Activity relevance
- Constraint handling (dates, budget)
- Cost calculation accuracy
- Itinerary feasibility
- Alternative suggestions quality
