# Data Analysis Agent

## Overview
An autonomous agent that analyzes data by executing SQL queries, generating reports, creating visualizations, and discovering insights. Built with AWS Bedrock (Claude 3.5 Sonnet).

## Purpose
Demonstrates data-driven agent workflows:
- Autonomous SQL query generation and execution
- Multi-step analytics workflows
- Data validation and quality checks
- Report generation
- Visualization creation
- Insight discovery
- Error recovery and refinement

## Features
✅ Natural language to SQL translation
✅ Query execution against databases
✅ Data validation and quality checks
✅ Report generation and formatting
✅ Chart/dashboard creation
✅ Statistical analysis
✅ Error recovery and query refinement

## Agent Loop
1. User asks analytic question
2. Agent plans analysis steps
3. Execute SQL queries
4. Validate data results
5. Generate visualizations
6. Create summary report
7. Return insights to user

## Testing Focus (Later)
- SQL correctness and safety
- Query result accuracy
- Data validation effectiveness
- Report completeness
- Visualization correctness
- Error handling and recovery
- Performance with large datasets
