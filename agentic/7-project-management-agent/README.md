# Project Management Agent

## Overview
An agent that parses requirements and automatically creates project plans with tasks, dependencies, effort estimates, and resource allocation. Built with Claude 3.5 Sonnet.

## Purpose
Demonstrates task breakdown and planning workflows:
- Requirements parsing
- Task decomposition
- Dependency identification
- Effort estimation
- Resource allocation
- Risk identification
- Timeline generation

## Features
✅ Requirement parsing
✅ Task decomposition
✅ Dependency tracking
✅ Effort estimation
✅ Resource planning
✅ Risk assessment
✅ Critical path identification

## Agent Loop
1. User provides project brief
2. Agent parses requirements
3. Decompose into tasks
4. Identify dependencies
5. Estimate effort per task
6. Allocate resources
7. Identify risks
8. Generate project plan
