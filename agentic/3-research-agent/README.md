# Research Agent

## Overview
An autonomous agent that gathers information from multiple knowledge bases, synthesizes findings, and creates comprehensive research summaries. Built with Claude 3.5 Sonnet.

## Purpose
Demonstrates multi-source information gathering:
- Search across multiple knowledge bases
- Information aggregation and synthesis
- Source comparison and conflict resolution
- Research report generation
- Citation management
- Confidence scoring

## Features
✅ Multi-source search capability
✅ Information aggregation
✅ Source agreement scoring
✅ Contradiction handling
✅ Research report generation
✅ Citation tracking
✅ Confidence assessment

## Agent Loop
1. User provides research question
2. Agent searches multiple sources
3. Gather information from each source
4. Synthesize and compare findings
5. Detect contradictions/agreements
6. Generate research summary
7. Include citations and confidence scores

## Testing Focus (Later)
- Search completeness across sources
- Synthesis accuracy
- Citation correctness
- Confidence scoring validity
- Source diversity handling
- Contradiction resolution
- Report quality and structure
