# E-Commerce Agent

## Overview
An autonomous shopping assistant that searches products, makes recommendations, handles checkout flows, and manages transactions. Built with Claude 3.5 Sonnet.

## Purpose
Demonstrates customer-facing transaction workflows:
- Product search and discovery
- Personalized recommendations
- Inventory checking
- Cart management
- Checkout flow
- Payment processing
- Order confirmation

## Features
✅ Product search
✅ Recommendation engine
✅ Inventory management
✅ Cart operations
✅ Checkout flow
✅ Payment processing
✅ Order tracking
✅ Customer support integration

## Agent Loop
1. User describes product need
2. Agent searches catalog
3. Generate recommendations
4. User selects products
5. Check inventory
6. Add to cart
7. Process checkout
8. Handle payment
9. Confirm order
