# Code Review Agent

## Overview
An agent that performs automated code reviews by running static analysis, checking style/patterns, identifying bugs, and suggesting improvements. Built with Claude 3.5 Sonnet.

## Purpose
Demonstrates quality assurance workflows:
- Static analysis execution
- Code style checking
- Pattern violation detection
- Security issue identification
- Performance recommendations
- Suggestion generation
- Report generation

## Features
✅ Static analysis execution
✅ Style and pattern checking
✅ Security vulnerability detection
✅ Performance issue identification
✅ Bug prediction
✅ Improvement suggestions
✅ Review report generation

## Agent Loop
1. User submits code for review
2. Agent runs static analysis
3. Check code style/standards
4. Identify security issues
5. Find performance problems
6. Generate improvement suggestions
7. Create review report
8. Return to user with feedback

## Testing Focus (Later)
- Analysis tool accuracy
- False positive rate
- Suggestion quality
- Security issue detection
- Performance issue detection
- Suggestion relevance
- Report clarity and actionability
