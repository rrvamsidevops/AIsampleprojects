# HR/Recruitment Agent

## Overview
An agent that automates recruitment workflows by parsing job descriptions, screening resumes, matching candidates to roles, and scheduling interviews. Built with Claude 3.5 Sonnet.

## Purpose
Demonstrates HR automation workflows:
- Job description parsing
- Resume screening
- Candidate matching
- Bias detection
- Interview scheduling
- Candidate communication
- Pipeline management

## Features
✅ Job description analysis
✅ Resume parsing
✅ Candidate matching
✅ Bias detection and mitigation
✅ Interview scheduling
✅ Candidate communications
✅ Pipeline tracking

## Agent Loop
1. Job posting created
2. Agent analyzes requirements
3. Screen incoming resumes
4. Match candidates to role
5. Detect potential bias
6. Rank qualified candidates
7. Schedule interviews
8. Send notifications
9. Track pipeline

## Testing Focus (Later)
- Job matching accuracy
- Resume parsing correctness
- Candidate matching relevance
- Bias detection accuracy
- Schedule conflict resolution
- Communication clarity
- Fairness across demographics
- Compliance with labor laws
