# Conversational Knowledge Base

## Overview
An interactive RAG chatbot that maintains conversation context while continuously refining retrieved information. Users can ask follow-up questions, request clarifications, and explore topics iteratively.

## Purpose
Demonstrates conversational RAG patterns:
- Context retention across turns
- Query refinement and clarification
- Progressive information gathering
- Anaphora resolution (reference handling)
- Query rephrasing for better retrieval
- User feedback incorporation

## Features
✅ Multi-turn conversation
✅ Query refinement across turns
✅ Context-aware retrieval
✅ Clarification requests
✅ Progressive information gathering
✅ User feedback integration
✅ Retrieved source tracking

## Testing Focus (Later)
- Context consistency across turns
- Query refinement effectiveness
- Clarification accuracy
- Retrieved context stability
- Conversation flow naturalness
- Token efficiency per session
