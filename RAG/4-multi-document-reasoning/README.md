# Multi-Document Reasoning

## Overview
An advanced RAG system that retrieves and synthesizes information from multiple documents to answer complex queries requiring cross-document reasoning. Built with Claude 3.5 Sonnet.

## Purpose
Demonstrates complex RAG scenarios:
- Comparison across documents (contracts, research papers)
- Contradiction detection and resolution
- Information synthesis and aggregation
- Temporal reasoning (document dates/versions)
- Confidence scoring based on agreement
- Bias detection from source diversity

## Features
✅ Multi-document retrieval
✅ Comparative analysis
✅ Contradiction detection
✅ Source agreement scoring
✅ Synthesis and summary generation
✅ Temporal document tracking
✅ Bias analysis from multiple sources

## Testing Focus (Later)

- Source agreement metrics
- Handling conflicting information
