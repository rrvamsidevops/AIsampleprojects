# Document Q&A Agent

## Overview
A RAG application that enables users to upload and query multiple documents (PDFs, reports, research papers) with semantic search and retrieval. Built with AWS Bedrock (Claude 3.5 Sonnet) + vector embeddings.

## Purpose
Demonstrates advanced RAG concepts:
- Multi-document retrieval and ranking
- Cross-document comparison and synthesis
- Document metadata management
- Citation tracking with source references
- Handling document structure (sections, headings, tables)

## Features
✅ Multi-document upload and indexing
✅ Semantic search across document collection
✅ Relevance ranking and filtering
✅ Citation with source and page numbers
✅ Document metadata extraction
✅ Chunk-level retrieval with context preservation
✅ Interactive document exploration

## Testing Focus (Later)
- Retrieval accuracy across multiple documents
- Citation accuracy and completeness
- Handling conflicting information
- Cross-document consistency
- Latency with large document sets
- Cost optimization for batch processing
