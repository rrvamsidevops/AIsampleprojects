# Product Catalog Search with Recommendations

## Overview
An e-commerce focused RAG system that searches product catalogs, provides recommendations, and handles compatibility checking. Optimized for retail and marketplace scenarios.

## Purpose
Demonstrates commercial RAG applications:
- Natural language product search
- Recommendation generation
- Compatibility checking (size, color, specs)
- Price comparison
- Stock availability checking
- Review synthesis
- Upsell/cross-sell suggestions

## Features
✅ Product catalog search
✅ Natural language matching
✅ Recommendation engine
✅ Compatibility checking
✅ Price comparison
✅ Availability tracking
✅ Review aggregation
✅ Upsell suggestions

## Testing Focus (Later)
