# Code Search & Explanation

## Overview
A specialized RAG system for searching and understanding code repositories. Enables semantic search over code, function documentation lookup, and code explanation with Claude 3.5 Sonnet.

## Purpose
Demonstrates domain-specific RAG:
- Code-aware semantic search
- Function/class signature matching
- Dependency graph awareness
- Code snippet recommendations
- Language-specific parsing
- Integration with version control

## Features
✅ Repository indexing (GitHub/local)
✅ Function and class search
✅ Semantic code similarity
✅ Dependency tracking
✅ Documentation extraction
✅ Code snippet recommendations
✅ Multi-language support (Python, JavaScript, Java, Go)

## Testing Focus (Later)
- Code semantic accuracy
- Function signature matching
- Dependency correctness
- Language-specific parsing
- Performance on large repos
- False positive rate in recommendations
